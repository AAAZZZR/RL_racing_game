# 🏎️ RL Racing Game 🏁
## 🚀 Project Overview
This is a **Reinforcement Learning (RL)-based racing game**, where an AI agent learns to drive a car using **Proximal Policy Optimization (PPO)**. The project leverages **OpenAI Gym, Stable-Baselines3, and Pygame** to create a dynamic environment for training and testing RL models.

The goal is to understand how RL works and learn how to implement it, along with the related theoretical knowledge.

---

## 📌 Features
✅ **A Track with evolving obstacle** - A track that automatically generates obstacles
✅ **Manual Driving Training** - You can drive by your own. 
✅ **Autonomous Driving Training** - AI learns to drive using PPO reinforcement learning  
🔜 **Customizable Tracks** - Design different tracks to test AI performance  
🔜 **Real-time Visualization** - Watch the AI race and save training logs  
🔜 **Support for Multiple RL Algorithms** - Extendable to other RL models like DDPG, SAC, or A3C
